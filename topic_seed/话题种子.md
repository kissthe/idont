### T01 魏山 · 武汉 · 外卖调度

- **人设：** 32 岁，以前跑过两年单，现在坐调度台。住城中村，楼下是修电瓶车的。说话短，报路况和数字。
- **日常支线：** ① 电瓶车控制器进水 → 换成国产件 → 仍异响 ② 调度系统把超时单甩给他 ③ 楼下修车铺老崔欠他一盒烟
- **M01 fear：** 前年暴雨，单车在立交底积水里侧翻，左膝磕护栏，当时没人停。后来怕的不是下雨，是**积水反光的柏油 + 护膝那条荧光条贴地**。
- **M02 anger：** 平台把一单医药柜夜配派成「可延迟」，病人家属在电话里骂了他整段录音。
- **主线索（可上图）：** 积水路面、车灯拉成一条的倒影、荧光护膝贴地。  
  **属性：** 积水 + 夜间车灯倒影才触发；干柏油、白天积水都不触发。
- **近错：** 洗车店地面有水、晴天立交桥。
- **具名物：** 老崔、左膝那条旧护膝、调度台的红色超时条。
- **不要写：** 把所有雨天都写成创伤。

### T02 安秋 · 昆明 · 花店店员

- **人设：** 26 岁，在花市口一家小店剪枝、写贺卡。合租，窗台常有掉下来的花瓣。少问别人私事。
- **日常支线：** ① 店里新进的鲜花桶漏水 ② 学用针式打印机打价签 ③ 合租室友把冰箱调得太冷，香菜结霜
- **M01 sadness：** 前男友最后一次出现是进店买一束白色洋桔梗，玻璃纸反光很亮，他没留电话。之后这种花她能插，但会先把玻璃纸换成哑光的。
- **M02 anxiety：** 婚礼单当天主花到货少了两扎，新娘在化妆间等。
- **主线索：** 白色洋桔梗 + 亮面玻璃纸反光（同图配对见第三节）。  
  **属性：** 白洋桔梗 + 亮玻璃纸；裸枝或哑光包装不触发。
- **近错：** 白色满天星、黄菊、超市仿真花。
- **具名物：** 店长姨、漏水的蓝桶、针式打印机。

### T03 沈朗 · 沈阳 · 呼吸科夜班护士

- **人设：** 34 岁，夜班为主，住护士宿舍。说话先报数值：血氧、滴速、几点叫的二线。
- **日常支线：** ① 宿舍热水器跳闸 ② 夜班餐的鸡蛋羹总是凉的 ③ 轮转表把他和老护士对调
- **M01 anxiety：** 独立值夜班第二周，走廊尽头 lone 的绿色出口灯底下，第一次遇到抢救。后来空走廊 + 那盏绿灯会让他走快一步。
- **M02 sadness：** 长期住院的大爷出院那天把未拆的饼干塞给他，一周后床位换人。
- **主线索：** 夜间空走廊尽头的绿色安全出口灯（同图配对）。  
  **属性：** 夜间 + 空走廊 + 那盏灯；白天人来人往的同一条走廊不触发。
- **近错：** 商场疏散灯、停车场绿灯、病房床头绿灯。
- **具名物：** 二线手机、凉鸡蛋羹、那包没拆的饼干（不要反复当道具）。

### T04 蒋茉 · 成都 · 中学音乐老师

- **人设：** 29 岁，教合唱，住学校周转房。周末去九眼桥附近找便宜的谱架。说话会哼半句再改口。
- **日常支线：** ① 谱架螺丝总松 ② 合唱队有人假声破了 ③ 周转房楼道堆纸箱，物业不让
- **M01 anxiety：** 家长会在阶梯教室，翻椅收起来的金属声里，有家长当众说她「只会带学生唱歌、中考没用」。她当时还在发歌单。
- **M02 comfort：** 期末一个不爱开口的学生第一次把高音唱稳，走的时候把铅笔忘在钢琴盖上。
- **主线索：** 阶梯教室翻椅连续弹起的金属声；可配图为翻起一半的连排椅。  
  **属性：** 连排翻椅金属声；单独一把木椅挪动不触发。
- **近错：** 食堂不锈钢餐盘、地铁闸机金属声。
- **具名物：** 松动谱架、那支忘在钢琴盖上的铅笔、物业老王。

### T05 梁伯年 · 广州 · 粤菜后厨

- **人设：** 41 岁，炒锅，住员工宿舍。手上有旧烫疤，不主动提。说话都是火候和叫料。
- **日常支线：** ① 新来的切配把姜切太粗 ② 宿舍风扇噪音 ③ 档口排风管要换，老板拖
- **M01 fear：** 学徒那年热油爆锅，油花溅左手背。后来怕的是**猛火炒锅边连续爆起的小油花**，不是「任何热油」。
- **M02 nostalgia：** 早年跟师傅凌晨四点熬上汤，蒸汽把眼镜蒙住，师傅把擦镜布扔过来。
- **主线索：** 猛火、炒锅边密的小油花、灶口那圈黑。可上图。  
  **属性：** 猛火炒锅 + 连续油花；平底锅煎蛋、煮汤的大泡不触发。
- **近错：** 街边炸油条、火锅翻滚、蜡烛油。
- **具名物：** 左手背疤、擦镜布（只出现一次）、切配阿志。

### T06 唐小满 · 西安 · 区图书馆

- **人设：** 36 岁，地方文献柜。住单位周转的两居，阳台上晒书。说话慢，先报索书号再说话。
- **日常支线：** ① 读者把胶带粘在书衣上 ② 空调冷凝水滴到硬纸盒 ③ 周末去城墙根修自行车座
- **M01 sadness：** 父亲留下的线装批注本被漏雨泡皱，竖排铅字发花。她后来还能摸这种纸，但会先看边角是不是翘的。
- **M02 anger：** 领导把地方文献柜改成「阅读角网红区」，原柜号作废。
- **主线索：** 发皱的竖排铅字页、翘起的纸角。可上图。  
  **属性：** 水渍 + 竖排 + 手写批注；全新竖排影印本不触发。
- **近错：** 报纸受潮、快递纸箱湿角、字帖。
- **具名物：** 冷凝水那只硬纸盒、旧索书号章、自行车座。

### T07 韩汀 · 青岛 · 游泳馆救生

- **人设：** 28 岁，倒班看泳池。住同事合租，阳台能看见一条干的游泳镜。话少，报泳道和人数。
- **日常支线：** ① 儿童池水温总被家长投诉 ② 合租的人用他的泳镜 ③ 馆里广播下午放同一首歌
- **M01 fear：** 自己十七岁在无泳道的深水区抽筋，岸上没人，水是均匀的深蓝。后来浅水区、有瓷砖格的池底都还好。
- **M02 happiness（轻）：** 第一次独立把一个小孩从水线旁抱上岸，小孩吐水后说「帽子还在」。
- **主线索：** 深蓝色、无泳道线、下午、岸上无人的水面（同图配对）。  
  **属性：** 深、无格、无人；浅水区能看见池底瓷砖则不触发。
- **近错：** 海边有人的浅滩、浴缸、蓝色地胶。
- **具名物：** 那副干泳镜、儿童池温度计、小孩的泳帽（不要变成吉祥物）。

## 五、每案 15 session 的题目怎么排

不要 15 段都围着记忆转。推荐日历（可左右平移日期）：

| 序号 | 角色 | 题目从哪来 |
|---:|---|---|
| S01–S03 | none | 日常支线①的开始；具名物出场 |
| S04 | encode M01 半截 | 只出现线索或只出现事件，不要两者加意义一次说完 |
| S05–S07 | none | 支线②、工作小事故、生活物件状态变化 |
| S08 | encode M01 补全 | 另一半证据；中间仍夹杂当天的闲事 |
| S09–S11 | none | 支线①要有进展（坏了→换了→仍有小问题） |
| S12 | encode M02 | 情绪类别与 M01 不同 |
| S13 | none | 完全无关的一次出门/排队/维修 |
| S14 | recall 或 control | 回忆则要状态变化；对照则给出可区分的当下原因，但**评测句不要靠「只是」句式** |
| S15 | none 或轻量 update | 以日常收束，不要升华 |

助手每段最多一个问号。用户消息长短不齐。具名物要跨 session 改变状态，不要每段都重新介绍。
